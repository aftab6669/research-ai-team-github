# research-ai-team-github# 🔬 ResearchAI Team

A simple modular multi-agent academic research assistant built with:

- Streamlit
- CrewAI
- Groq GPT-OSS 120B
- Crossref
- CrewAI tools

## Agents

1. Research Manager
2. Literature Researcher
3. Methodology Analyst
4. Critical Academic Reviewer
5. Academic Writer

## Tools

- Academic Literature Search
- Research Source Checker
- Safe Research Calculator

## Deployment

Deploy `app.py` on Streamlit Community Cloud.

Add this secret:

```toml
GROQ_API_KEY = "your-groq-api-key"
```

Never commit your API key to GitHub.
